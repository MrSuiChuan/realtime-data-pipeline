# 资产与项目 MCP 契约

服务名从 `.rtd/config.json` 的 `executors.mcp_asset` 读。用于项目/应用定位与资产知识检索。

## 用途与边界

- **项目定位**：验证项目名是否真实存在、是否有权限访问；不能替代元表搜索；
- **资产/表知识**：字段含义、业务说明、血缘的补充证据；
- **已知覆盖缺口**：资产索引对实时元表**覆盖不完整**——搜不到不等于不存在，必须回到元表搜索按名称完全相等确认；
- 血缘是多层视图，但与运维侧的一层血缘口径不同，报告里要标注来源。

## 与主流程的衔接

| 阶段 | 怎么用 |
| --- | --- |
| 研发流程「发现来源表」那一步 | 关键词不明确时辅助；拿到候选后回元表搜索精确确认 |
| 研发流程「理解表结构」那一步 | 作为元表字段描述的补充；**权威仍是元表详情** |
| 步骤 1e 来源表验证 | 辅助验证血缘与业务归属；血缘为空 ≠ 无下游 |
| 项目定位 | 验证项目可访问性，不用于"按名搜索任务证明项目存在" |
