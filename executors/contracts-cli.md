# 平台 CLI 契约

默认执行器（研发 + 运维）。真实命令名从 `.rtd/config.json` 的 `executors.cli.cmd` 读；本文件只写**契约形状**，不写具体命令串。

## 能力探测

- 判据是**帮助正文**：把帮助原文存下来，在里面 grep 命令名与 flag；不要用版本号，也不要用退出码；
- 未知子命令加帮助参数可能返回父命令帮助并退出 0——那不是"命令存在"的证据；
- 探测结果写进 `governance/capability-matrix.json` 的 `executors.cli.known_gaps`，正文里不许内联"某版本不支持某命令"。

## 常用交互协议

| 场景 | 约定 |
| --- | --- |
| 未指定项目 | CLI 可能返回"请选择常用项目"的特定错误码；按原顺序展示让用户选，**不猜 ID** |
| 异步动作 | 返回受理态与追踪 ID；按 `limits.poll_interval_s` 轮询到终态 |
| 结构化输出 | 需要证据的动作一律要求 JSON 输出（`evidence add` 只收结构化证据） |
| 名称搜索 | 模糊匹配；必须回读并按名称**完全相等**确认 |

## 错误分类（分诊用，不是错误码字典）

| 类别 | 特征 | 处置 |
| --- | --- | --- |
| 参数错 | 本地校验就报 | 改参数重试 |
| 权限错 | 明确提到权限/角色 | 按渠道申请；元表权限 ≠ 底层存储权限 |
| 存储错 | 报错里带 DDL 与连接器 | 反推缺哪个存储的权限 |
| 服务端错 | 5xx / 追踪 ID | 保留追踪 ID，按仲裁规则决定是否回退 |
| 超时 | 无明确终态 | 先查原对象状态，**不重发** |
