# 研发域 MCP 契约

服务名从 `.rtd/config.json` 的 `executors.mcp_dev` 读。负责任务全生命周期、迁移、目录、元表。

## 已知限制

- 配置编辑类工具**通常只能处理本执行器创建的对象**——CLI 建的对象不要交给它改（`governance/executor-arbitration.md` 第 3 条）；
- 迁移类工具是"一条命令携带多阶段"的形态：全量分片 / 完整性校验 / 查重 / 创建 / 写入 / 编译由它内部串起来；Skill **不自己拼内容**，也不在失败后另起第二个目标；
- 异步动作返回受理态，需要按 `limits` 轮询到终态才作数。

## 元表相关

| 动作 | 要点 |
| --- | --- |
| 搜索数据源 | 按类型/项目/关键词；精确匹配后记 ID 与官方标志 |
| 创建/编辑 | 展示完整定义（columns 全量语义）并确认；编辑是字段级合并但 columns 一旦传入即全量替换 |
| 提交 | 与创建/编辑**分开确认**；物理表缺失是提交失败后的回退动作 |
| 发布校验 | 待人工确认时原样返回链接并停止 |
| 发布 | 校验通过后再次回读展示，单独确认 |

字段级契约见 `datasources/metatable-lifecycle.md`；能力缺口见 `governance/capability-matrix.json`。
