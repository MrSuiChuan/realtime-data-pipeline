# 运维域 MCP 契约

服务名从 `.rtd/config.json` 的 `executors.mcp_ops` 读。本文件写"这些能力在使用上有什么坑"。

## 定位与状态

| 能力 | 必须知道的限制 |
| --- | --- |
| 任务搜索 | 入参可能包在命令对象里；游标分页；owner 是精确筛选，名称是模糊筛选；**首屏为空不代表不存在** |
| 拓扑查询 | 返回运维侧标识与实例列表；拓扑里的标识可能是内部标识，单独保存，**不要覆盖文件级 ID**；部署仍用开发态文件级 ID |
| 任务详情（批量） | 有批量上限，超限要分批；简式/详式两种模式，**只有详式返回 SQL / 执行计划 / 近期错误**；带待发布版本时，顶层字段表示**当前运行版本**，待发布内容在专门嵌套字段里 |
| 任务血缘 | 上下游各一层，**不是全图**；按任务 ID 格式自动识别类型 |
| 变更记录 | 必传起止时间且起点早于终点；条数有默认值与上限；**时间相关 ≠ 因果** |

## 指标

目录 → 趋势 → 原始采样三级：

- 目录里存在 ≠ 该作业有数据；空序列 ≠ 零值；
- 趋势有采样点数默认值与范围上限；原始采样有最长回溯窗口与分页上限；
- 导出链接有时效，按敏感临时链接处理。

## 变更类（部署 / 停止 / 下线 / 取消部署）

| 动作 | 规则 |
| --- | --- |
| 部署 | 用开发态文件级 ID；每个计划必须有精确任务 ID 与操作类型；重启类必须带**用户确认的恢复点**；带恢复点参数与不带恢复点参数的场景要分清；缺任一真实值即停止，**不填空串** |
| 热更新 | 仅限特定组合，且不能带恢复点参数；不保证运行参数同步生效 |
| 停止 | 用户主动要求 + 二次确认；不重复发起；超时先查原状态 |
| 下线 | 必须先有停止成功的证据；进度查询可能推进清理，不是无副作用预检 |
| 取消部署 | 仅特定任务类型；不能绑定流程 ID 做条件取消；"动态最新目标"要用户明确接受并发风险，否则走人工路径 |

## 运行参数与执行计划

- 运行参数更新有作用域参数，**默认作用域可能同时影响两层版本**，必须按意图显式指定；
- 写后返回的前后值**不是两份独立快照**，要重新查询核实；
- 执行计划更新需全量结构与连接；**无并发保护（无 CAS）**，读后写存在竞态——发现他人变更就停止旧提交；
- 重置只生成预览，不持久化、不被部署消费。

## 资源

余量与总量来自不同来源，分别返回；缺值不代表有余量；不自行推算"可用余量"。
