# 引擎侧 MCP 契约（只读）

服务名从 `.rtd/config.json` 的 `executors.mcp_engine` 读。

## 只读硬边界（来自 `governance/safety-constitution.md` 第二节，重申一次不嫌多）

允许：查询异常、日志、检查点、算子与运行态；火焰图采样（须先定位目标、评估采样开销、按需使用）。

禁止：启动作业 / 重启 / 停止 / 热启动，以及一切非查询操作。**不因平台侧工具不可用、失败或权限不足而改走引擎侧。**

## 使用要点

| 要点 | 说明 |
| --- | --- |
| 身份 | 先查作业身份（集群、UI 地址、版本、失败 traceId），再按症状取最少数据 |
| 每次调用 | 回答一个问题，并写下它支持/反驳了哪条假设 |
| 日志 | 必带窗口 + 关键词 + 行数上限；日志有截断与延迟 |
| 火焰图 | 先定位目标任务与实例，评估开销；采样授权**不**扩展为变更授权 |
| jobId | 随实例变化，重启后重新映射，不复用旧值 |

## schema 快照

`executors/schemas/` 放工具 inputSchema 快照，用于离线核对字段。**快照是快照，不是可用性证明**——真正调用前按当前会话真实 schema 再核一次。
