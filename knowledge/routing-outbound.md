# 出站路由

本插件只管实时域的开发与运维。下面这些意图**转出去**，转出时要明确告诉用户"这已转出本插件"。

| 出站意图 | 去哪 | 怎么判断走了这条 |
| --- | --- | --- |
| 离线任务提交发布 / 数据探查 | `data-development-plugin:ddp-submit` | 用户要建数据需求工单、跑离线流水线 |
| 离线研发全流程（设计→研发→测试→部署） | `data-development-plugin:ddp-start` | 目标不是实时任务 |
| 补数据 / 回刷离线基线 / 同步任务 / 离线数据质量 | `data-development-plugin:ddp-submit` | 涉及调度基线与离线表 |
| 口径与规则的沉淀、知识库查阅 | `knowledge-base-plugin:kbp-status` | 用户要查/维护知识库与质量规则 |
| 知识库生成与发布 | `knowledge-base-plugin:kbp-generate` | 用户要从元数据生成域知识 |

## 规则

1. **目标必须在安装时探测一次**：`tools/validate_plugin.py` 第 8 项会检查本文件里出现的技能包是否真的装在本机；没装就把那一行标成"未安装"，给出人工路径；
2. 不指向不存在的技能名（这就是死链，和"引用了不存在的文件"是同一类缺陷）；
3. 转出后不要顺手代做：离线域的门控与证据由那边的插件负责。
