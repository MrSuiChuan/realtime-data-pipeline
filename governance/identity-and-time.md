# 身份与时间

实时域的事故多半出在"拿错了 ID"和"算错了时间"。本文件是全包唯一的标识与时间规则源。

## 一、八类标识（全部按字符串处理，不做数值转换）

| 标识 | 来源 | 用途 | 坑 |
| --- | --- | --- | --- |
| 文件级 ID | 平台查询返回 | 编辑、编译、提交、发布、部署入参 | 部署时用运维侧短 ID 会报"文件不存在" |
| 内部标识 | 拓扑响应可能返回 | 仅单独保存 | 不覆盖文件 ID |
| 实例 ID | 拓扑/详情 | 按任务形态取用 | 某一形态不传实例 ID，另一形态用唯一数字 ID |
| 任务 ID | 拓扑/详情 | 部署 plan 的精确目标 | 数字短 ID ≠ 文件 ID |
| 站点 + 作业唯一 ID | 引擎侧身份查询 | 引擎侧取证入口 | 与引擎 jobId 不是一回事 |
| 引擎 UI 地址 + jobId | 引擎侧身份查询 | 定位运行实例 | 重启后 jobId 变化，不能复用旧值 |
| 节点 uid | 执行计划 | 调参时精确定位 | 禁止按数组下标定位目标节点 |
| 追踪 ID | 每次写操作受理返回 | 追踪、超时后核对 | 原样保存，不重编 |

长 ID 一律保持字符串：数值化会在部分宿主上丢精度。

## 二、三类 ID 的流转

1. **开发态长 ID**：编辑 → 编译 → 提交 → 发布全程使用，也是部署入参；
2. **运维侧短 ID**：只用于识别对象，**不能**当部署入参；
3. **实例 ID**：按任务形态取用，形态不同传参不同，缺真实值即停，不填空串。

## 三、时间

- 所有时间带时区；展示与写入都用用户确认的那个时区的值，歧义时**部署前**澄清；
- 恢复点/重置时间必须来自用户确认，**禁止自动取当前时间**；
- 轮询节奏与超时上限从 `.rtd/config.json` 的 `limits` 读，工作流只写"按配置轮询至终态"；
- 指标与日志查询必须带**窗口**：同窗口、同基线才可比。跨窗口对比要在报告里写明。

## 四、对象同一性的判断顺序

1. 文件级 ID 相等 → 同一对象；
2. 名称相等但 ID 不同 → **不是**同一对象（同名不同版本、不同项目各有一份是常态）；
3. 名称模糊命中（搜索前缀/子串命中）→ 必须回读确认完全相等才算命中，避免命中历史版本。
