# 安全宪法

全包唯一的门禁层。所有工作流**引用**本文件，不准复制条款；要改规则改这里，改完跑 `validate_plugin.py`。

## 一、公共门禁（9 条）

1. **写前确认**：任何写操作前，展示精确对象、字段差异与影响范围，取得**当次**明确确认。发布、启动、元表创建与提交、执行计划更新、运行参数更新各自另有专用门禁（在对应 runbook 里），本条的通用要求不被它们替代。
2. **确认不传递**：安装同意 ≠ 回退同意 ≠ 业务操作授权。高风险动作各自独立确认；用户认可了诊断结论，不等于授权按结论动手。
3. **高风险动作白名单**：启动 / 重启 / 热更新 / 停止 / 下线 / 取消部署 / 发布 / 迁移启动，必须"用户主动要求 + 精确核对对象 + 独立确认"三件齐备。
4. **`--yes` 的语义**：它是工具自身的硬门禁开关，**不构成**对话确认的替代。禁止 Agent 自行追加；用户没说过就是没说过。
5. **数据主权**：启动会真实消费数据、写下游、占引擎资源。工具调用里带来源标记（如 aiOperation）只表示调用来自 Agent，不代替任何确认。
6. **启动双确认（迁移场景最严）**：必须确认原任务已停止（跨会话不得沿用隐含记忆）+ 取得用户确认的恢复点/重置时间（**禁止自动填当前时间**）。"源任务已停止"是**声明**，不是状态证明——要证据就回读原对象状态。
7. **引用门禁**：实时任务只能引用**已发布**元表。存在开发版本 ≠ 可用；来源表不可见时优先排查项目与权限，**禁止创建空壳来源表**充数。
8. **ID 主权**：目录、项目、任务、实例、追踪 ID 必须来自本次真实查询。禁止从 URL 取参数当接口入参，禁止猜测或复用其它任务的 ID。
9. **链接主权**：每个阶段无论成败，返回本次真实获得的平台链接；没拿到就明说没拿到，禁止拼接或复用其它任务的链接。

## 二、引擎侧只读硬边界

```
允许：全部只读查询 + 火焰图采样（须先定位目标、评估采样开销、按需使用）
禁止：启动作业 / 重启作业 / 停止作业 / 热启动 及一切非查询操作
      —— 不因平台侧工具不可用、失败或权限不足而改走引擎侧
      —— 不以任何 CLI、代理或脚本路径绕过
      —— 采样授权不扩展为作业变更授权
变更统一走平台侧（部署/停止/下线）；平台侧失败 → 如实报告阻塞
```

这条边界是无条件的：任何工作流（含"从咨询转操作"的路径）都受它约束。

## 三、unknown 全局语义（8 条）

未发现 ≠ 未安装；空列表 ≠ 无数据；查询失败 ≠ 零事件；运行中 ≠ 健康；
受理成功 ≠ 生效；部署成功 ≠ 目标生效；时间相关 ≠ 因果；用户认可 ≠ 证据。

逐条的反例与处置见 `governance/anti-patterns.md`。

## 四、门禁与阶段键的对应

引擎写的阶段键必须能追溯到本文件的条款；键名与含义见 `engine/rtd.py` 与 `workflows/`。

| 阶段键 | 对应条款 | 证据 |
| --- | --- | --- |
| `refs_published` | 第 7 条 | 引用元表已发布版本回读 |
| `compile_ok` | 第 1、3 条 | 编译终态回执 |
| `debug_confirmed` | 第 1、5 条 | 调试模式选择 + 当次确认记录 |
| `sla_decided` | 第 1 条 | SLA 决策记录（"跳过"也是决策） |
| `submit_ok` | 第 1 条 | 提交终态 + 发布前校验状态 |
| `publish_ok` | 第 1、3、9 条 | 发布终态 + 待发布对象回读 + 平台链接 |
| `start_confirmed` / `source_stopped` / `reset_time` | 第 3、6 条 | 三项独立确认记录 |

## 五、违反时的处置

- 门禁未满足而用户要求继续 → 停下来复述缺哪一项，不"先做着看"；
- 发现自己在没有当次确认的情况下已发起写操作 → 立即停止链上后续步骤，报告已提交的确切对象与追踪 ID，交用户决定；
- 证据不足但结论有用 → 按 `governance/response-contracts.md` 标"暂评/未决"，不升格为结论。
