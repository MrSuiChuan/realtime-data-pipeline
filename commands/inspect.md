# rtd-inspect — 单任务或批量健康巡检

流程见 `workflows/runbook-inspection.md`。**巡检只读**，不改任何线上状态。

## 要点

1. 预算从 `.rtd/config.json` 的 `limits` 读；触顶即停，交**部分覆盖报告**并写明缺口；
2. "预期集合"与"实际集合"独立对照：当前列表里没有 ≠ 原本不需要运行；
3. 上下游各查一层，四种"没有结果"（未采集 / 能力未发现 / 接口无样本 / 权限不足）分别记；**缺项 ≠ 正常**；
4. 采样规则：有洞不跨段、不补零；降采样不能证明持续越线；聚合值不当最差实例、内存多分支取最大不相加；
5. 下钻最多两个风险对象；**巡检中不生成火焰图、不自愈**。

## 交付

按 `governance/response-contracts.md`：五部分正文 + 取证附录 + 快照 + 评分。正常 / 异常 / 证据不足三种结果都必须交付；证据不足时给"已观测风险暂评分"，不虚构满分。

批量模式：每个对象独立产报告；暂评分不参与平均，**不生成"项目综合分"**。
